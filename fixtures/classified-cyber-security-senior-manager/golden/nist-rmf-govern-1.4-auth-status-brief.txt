### 3. Risk Management Process Description

The risk management process for APEX-7 operates as a continuous, documented evaluation cycle:

| Phase | Activity | Cadence | Evidence Artifact |
|-------|----------|---------|-------------------|
| Map | Fixture suite scope review and risk taxonomy update | Quarterly | Fixture bundle manifest |
| Measure | Behavioral evaluation runs (effectiveness, injection resistance, PHI leakage) | Monthly | Signed run JSON + evidence tarball |
| Manage | Gap triage, POA&M update, AO notification for significant findings | Per run | POA&M delta + AO memo if threshold breached |
| Monitor | Drift index computation across rolling 90-day window | Monthly | Drift report |

**Transparency mechanism:** All evaluation runs produce a signed evidence tarball (run_id, started_at, finished_at, config_hash, SHA256 manifest) retained for AO review. No evaluation result is consumed internally without an immutable record.
